# Data

These two datasets are joined onto each home sale by ZIP code. They're too large to keep in the repository, so download them here with these file names:

| File | Source |
| --- | --- |
| `population_by_zip_2010.csv` | 2010 US Census population by ZIP code, published by Google as the BigQuery public dataset `bigquery-public-data.census_bureau_usa.population_by_zip_2010` |
| `Public_Schools.csv` | HIFLD (Homeland Infrastructure Foundation-Level Data) Public Schools dataset, based on NCES data |

The King County house sales data used by the simulator lives in [`simulator/kc_house_data.csv`](../simulator/kc_house_data.csv).
